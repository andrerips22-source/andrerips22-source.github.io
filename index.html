rips-clips

A personal publishing tool for the "Andre | Pokemon pulls" channels.

rips-clips is a small private tool run by one creator on their own computer. It uploads short videos that the creator made to the creator's own YouTube, TikTok and Instagram accounts, and reads those accounts' own statistics (views, likes, comments, watch time) so the creator can see how the videos perform.

It is not offered to the public, has no user sign-up, and only ever connects to accounts owned by the creator.
